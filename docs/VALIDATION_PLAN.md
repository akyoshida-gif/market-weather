この計画に合意してから検証を始める。計画から外れる変更は、実行前にこの文書を更新して合意を取る。

## 0. 目的と評価の考え方

- 目的：**最終的にリターンが大きくなる「シグナル × 売買ルール」を見つける**こと。
- 勝率は重視しない。勝率10%でも当たりで大きく取れればよい。勝率80%で1回+1%でも、積み上げられればよい。
- したがって主な評価は次のとおり。
  1. **1回あたりの期待値**（コスト差し引き後の平均損益）
  2. **合計リターン**（資金の配分ルールを決めたうえでの累積）
  3. **右側の大きさ**（+20%・+50%・+100%に届いた割合、上位10%の平均）
  4. 安定性（時期を分けても崩れないか）
- 日足データなので、デイトレードは対象外。**数日〜数か月のスイング以上**が対象。

## 1. 前提

| 項目 | 内容 |
|---|---|
| データ | 日足（始値・高値・安値・終値・出来高・分割）。2010年1月〜2026年10月 |
| 対象A | **米国の上場普通株すべて**（約5,900銘柄、小型株を含む） |
| 対象B | **その時点の S&P 500 構成銘柄**（過去の入れ替え履歴から再現） |
| 結果の扱い | A と B を並べて表示。結論は B を基準にし、A で小型株特有の傾向を見る |
| 対象Bの欠け | 指数から外れた銘柄の株価は無料では取れない（199銘柄中、Yahoo で使えるものはほぼなし）。欠けの割合：2010年32%・2014年25%・2018年15%・2022年7%・2024年4%。**オーナー判断（2026-10-26）：欠けは受け入れ、対象Bは2018年以降を重視**。それ以前は参考扱い |
| 期間の表示 | 全期間に加え、**4つの時期（2010–13／14–17／18–21／22–26）**と**直近3年・直近1年**を必ず並べる |
| 規模の区分 | 時価総額の過去データがないため、**20日平均の売買代金**と**株価**で区分（例：売買代金 1億ドル超／1000万〜1億／100万〜1000万）。時価総額は SEC の発行済株式数が使える範囲で補助的に使う |
| 流動性 | 20日平均の売買代金100万ドル未満、株価1ドル未満の日は対象外（実際に売買できない） |
| コスト | 往復で、株価20ドル以上は0.1%、5〜20ドルは0.3%、5ドル未満は1.0%。窓開けで約定がずれた分は実際の価格で計算 |
| 異常データ | 株式分割の日や、1日で60%超動いた日の前後は除外（取得元のデータ誤りのため） |

### 既知の限界（受け入れる）
- 上場廃止になった銘柄の株価は取れないため、対象Aは「生き残った銘柄」に偏る。対象Bも、廃止された元構成銘柄の株価が取れない分は欠ける（欠けた割合を報告する）。
- アナリストの決算予想（コンセンサス）は無料で手に入らないため、「予想との差」は使えない。決算への株価の反応で代わりにする。
- 個別銘柄のオプションは過去データがないため、過去の検証には使えない。

## 2. 調べる条件（シグナル）

株価・出来高だけでなく、**取れる過去データはすべて条件の候補にする**。データによって過去の長さが違うため、使える期間も併記する。

| 分類 | 条件の例 | 過去データ | 状態 |
|---|---|---|---|
| チャート・テクニカル | 移動平均（パーフェクトオーダー・GC/DC）、一目均衡表、MACD、RSI、ストキャス、ボリンジャー、フィボナッチ、ローソク足の形、高値・安値の位置 | 2010〜 | 取得済み |
| 出来高 | 出来高の急増・閑散、売買代金、OBV | 2010〜 | 取得済み |
| 空売り（日次） | FINRA 空売り比率の水準・急低下（買い戻し）・急上昇 | 2018〜可能（今は2021〜を取得中） | 取得中 |
| 空売り残高 | 空売り残高の増減、浮動株比、カバー日数 | 2021〜（5年） | 一部取得済み |
| 受け渡し不履行・空売り規制銘柄 | 不履行の急増、規制リスト入り | 2008〜 | 未取得 |
| 決算 | 決算発表（SEC 8-K 2.02）の翌日の窓・出来高・引けの強さ（決算への反応） | 2001〜 | 取得中（過去分） |
| 開示イベント | 重要な契約（8-K 1.01）、役員の異動、大量保有（13D/13G）、自社株の発行・増資の届出（S-1/S-3/424B）、上場基準違反の通知 | 2001〜 | 取得中（過去分） |
| インサイダー売買 | 役員の市場での買い（金額・人数・複数人の同時買い） | 2006〜 | 未取得 |
| 株数・時価総額 | 発行済株式数の増加（希薄化）、時価総額の区分 | 2009〜 | 未取得 |
| 市場全体・マクロ | 指数のトレンド、上昇銘柄の割合、VIX と期間構造、信用スプレッド、金利、ドル、原油、セクターの循環、市場全体のプット/コール比率、CFTC の先物ポジション | 2006〜（一部はもっと前） | 一部取得済み |
| オプション（個別銘柄） | プット/コール比率、IV、コールの建玉の急増 | **2026/10/22〜のみ** | 過去の検証には使えない。デモトレードで記録が貯まってから使う |

- 「未取得」「取得中」のものは、計画の合意後に取得してから使う。
- 過去が短いデータ（空売り比率・空売り残高）を含む組み合わせは、そのデータがある期間だけで評価し、期間を明記する。

### 組み合わせの探し方（数の上限は設けない）
- **数の上限は設けない**。複数の条件が重なったときに強くなる可能性を捨てないため。
- 1万〜数十万通りを総当たりにすると計算も偶然も膨らむので、次の2つで探す。
  1. **段階的に条件を足していく探索**：1個 → 2個 → 3個 → … と、各段階で開発期間の成績が良い上位を残して次の条件を足す。成績が改善しなくなるか、件数が少なくなりすぎたら止める。
  2. **決定木・勾配ブースティングによるルール抽出**：機械学習に「どの条件の組み合わせのときに大きく上がったか」を学ばせ、成績の良い枝（条件の組み合わせ）をルールとして取り出す。人が思いつかない組み合わせも拾える。
- 偶然に対する歯止めは数の制限ではなく、**未使用の期間での確認・時期別の安定性・上位5日を除いた成績**で行う（5章）。
- 1つのパターンに必要な最低件数：開発期間で30件以上。それより少ないものは「参考」として別枠で表示する（出現は少ないが強いパターンを捨てないため）。

## 3. 方法A：シグナルの後、株価はどう動いたか（イベントスタディ）

売買ルールを決めずに、シグナルの**後の値動きそのもの**を測る。

- 起点：シグナル日の翌日の寄り付き
- 測る期間：1・3・5・10・20・40・60・120営業日後
- 測るもの
  | 指標 | 意味 |
  |---|---|
  | 平均・中央値の騰落率 | 全体としての伸び |
  | **同じ日の対象銘柄全体の平均との差** | 地合いの影響を除いた「その条件の力」 |
  | 期間中の**最大の上昇幅（MFE）** | どこまで伸びる余地があったか（利確をどこに置くべきか） |
  | 期間中の**最大の下落幅（MAE）** | どこまで逆行するか（損切りをどこに置くべきか） |
  | +20%・+50%・+100%に届いた割合 | 大きく取れる可能性 |
  | 騰落率の分布（下位10%・上位10%） | 当たりの大きさと外れの大きさ |
- **値動きの大きさで分けて見る**：ATR（1日の平均値幅）÷株価で4段階に分け、値動きの大きい銘柄を不利に扱わないようにする
- **強い日の分析**（ご指摘④）：シグナルが同じ日に大量に出た日（暴落後の反発など）だけを取り出し、その日に**どんな特徴の銘柄が特に強かったか**（値動きの大きさ・売買代金・直前の下落率・セクターETFとの関係・52週高値からの距離など）を比べる

この結果から「どの条件が、どの保有期間で、どれくらい伸びるか」を把握し、方法Bの売買ルールの候補を決める。

## 4. 方法B：売買ルールを付けた場合の損益

方法Aで有望だった条件に、**性格の違う決済ルール**を複数組み合わせて、実際の損益を測る。

### 4-1. 買い方
| 種類 | 内容 |
|---|---|
| 寄り付き買い | シグナル翌日の寄り付きで買う |
| 押し目の指値 | 翌日に、シグナル日の終値または安値付近まで下がったら買う（届かなければ見送り） |
| 高値更新で買い | 翌日に、シグナル日の高値を超えたら買う（勢いの確認） |

### 4-2. 決済のしかた（固定の4つの型はやめる）
| 種類 | 損切り | 利確 | 狙い |
|---|---|---|---|
| X1 期間固定 | なし | なし | 5・10・20・60・120日で決済。基準として使う |
| X2 構造ベース | シグナル日の安値、または直近10日の安値の少し下 | 直近の高値（抵抗線）または利確なし | チャートの根拠に沿った損切り |
| X3 トレーリング（ATR） | 買ってからの最高値 − 3ATR で追いかける | なし（伸びる限り持つ） | **大きく伸びる銘柄を取り切る** |
| X4 トレーリング（移動平均） | 終値が20日線（短め）または50日線（長め）を割ったら決済 | なし | トレンドに乗り続ける |
| X5 広めの固定幅 | −8%・−15%・−25% | +20%・+50%・+100% | 値動きの大きい銘柄向け |
| X6 組み合わせ | X2の損切り | 半分を+2Rで利確、残りはX3で追う | 早めに一部を確保しつつ大きな伸びも狙う |

- いずれも最長の保有期間を決める（例：短期30日、中期120日、長期250日）
- 損切り・利確の幅は、方法AのMFE・MAE（実際にどこまで伸び、どこまで逆行したか）の分布を見て決める

### 4-3. 測るもの
- 1回あたりの平均損益（%と、損切り幅を1としたR）、合計、勝率、平均利益／平均損失
- **右側の大きさ**：上位10%の取引の平均、最大の取引、利益全体に占める上位の取引の割合
- 保有日数の分布
- 期間別（4つの時期・直近3年・直近1年）

## 5. 試しすぎと「今の相場」の扱い（ご指摘③）

- 試した組み合わせの数を必ず報告する。
- 結果は次の段階に分けて扱う。古い時期に勝てないものも、捨てずに区別して残す。

| 段階 | 条件 | 扱い |
|---|---|---|
| **有力** | 4つの時期のうち3つ以上で期待値がプラス、かつ直近3年もプラス、かつ「同じ日の対象銘柄全体」より良い | デモトレードに入れる |
| **最近有効** | 直近3年と直近1年はプラスだが、古い時期は不安定 | 「今の相場向け」として印を付けてデモトレードに入れる（少額扱い） |
| **候補** | 全期間ではプラスだが時期によるばらつきが大きい | 記録のみ |
| **不採用** | 上記以外 | 理由を記録 |

- 上位5日を除いた成績も必ず併記する（数日の出来事だけに頼っていないかの確認）。

## 5-2. 方法Aの具体的な実行方法（実装：`jobs/event_study.py`）

| 項目 | 内容 |
|---|---|
| **開発期間** | **2010〜2021年（案・オーナー確認待ち）**。組み合わせの探索はこの期間の成績だけで行い、2022年以降は「未使用の期間」として確認に使う。空売り比率（2018〜）・空売り残高（2021〜）は開発期間が短くなる |
| 探索の目的の指標 | 開発期間の「同じ日の対象銘柄全体の平均との差」（超過リターン）の平均 |
| 探索する保有期間 | 短期5日・スイング20日・長期60日のそれぞれで探索（評価は全8期間で行う） |
| 段階的な探索 | 銘柄の条件1個から始め、各段階で上位40通りを残して条件（銘柄の条件＋市場全体の条件）を1つずつ足す。超過リターンが0.2%以上改善しない、または開発期間の件数が30件未満なら止める。最大8個 |
| 決定木 | 開発期間の行から最大300万行を抽出し、深さ6・1つの枝に最低2,000行の決定木を学習。平均を上回る枝を「条件 かつ 条件でない…」のルールとして取り出す |
| 重要度 | 勾配ブースティング（LightGBM）で、どの条件が効いているかの割合も出す |
| 判定 | 5章の4段階。「期待値」はコスト差し引き後の平均騰落率 |
| 強い日の分析 | 有望な上位30パターンについて、出現が最も多かった5日の銘柄を、値動きの大きさ・売買代金・直前5日／3か月の騰落率・52週高値からの距離で4つに分けて比べる |
| 実行場所 | 全銘柄で約1,100万行になり手元のPCではメモリが足りないため、GitHub Actions（手動実行）で行う。ログには進み具合だけを出し、結果は非公開の R2 にだけ保存する（対象ごとに途中保存） |
| 株価の基準 | Yahoo の株価は「今の時点で分割を調整した値」。時価総額・1ドル未満の除外・コストの区分・受け渡し不履行の比率は、分割の倍率で**当時の株価に戻して**計算する |
| 対象Bの比較の基準 | 「同じ日の S&P 500 構成銘柄の平均」との差（対象Aは米国株全体の平均との差） |
| シグナルの初日 | 対象外の行（売買代金不足など）を除く**前**の、その銘柄の前の営業日と比べて判定する（対象に入った日や指数に採用された日を「初日」と数えない） |
| データ開始前の期間 | 「条件が成り立たない」ではなく「データなし」として評価から除く |
| 開発期間の終わり | 保有期間 h のリターンが開発期間の中で終わる行だけで探索する（2021年末のシグナルの60日後＝2022年の値動きを使わない） |
| 異常データ | シグナルの5日前から保有期間の終わりまでに、分割の日または1日60%超の動きがあれば、その保有期間だけ除外 |
| t値 | 同じ日のシグナルは独立でないため、日ごとに平均してから計算する |
| 最低件数 | 4つの時期・直近3年・直近1年は、10件以上あるときだけ判定に数える。開発期間30件未満は「参考」 |
| **データが短い条件の判定（案・オーナー確認待ち）** | 「4つの時期のうち3つ以上でプラス」を、**データのある時期のうち4分の3以上（最低2つ）でプラス**と読み替える。4つの時期すべてにデータがある条件は従来どおり「3つ以上」。空売り比率（2018年8月〜）・空売り残高（2021年8月〜）は時期が2つしかないため、両方プラスが必要 |
| ETF | 普通株ではないため対象から除く（市場全体の条件の計算には使う） |
