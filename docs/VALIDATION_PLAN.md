# 検証計画（米国株・方法A／B）

状態：**改訂版 合意済み（2026-10-27）**　初版 2026-10-26
この計画に合意してから検証を始める。計画から外れる変更は、実行前にこの文書を更新して合意を取る。

改訂の理由（2026-10-27 のすり合わせ）：
- 初版は「どの時代でも通用するか」を重視しており、今の相場で強い手法ほど落としてしまう作りだった。
- オーナーとの合意で、目的を「聖杯（万能な手法）探し」から「**今の相場で強い武器を見つけること**」に改めた。
- あわせて、使う情報を数値の情報全般（マクロ・先行指標・セクターの循環など）に広げた。

## 0. 考え方（オーナーと合意した前提）

- **聖杯は存在しない。** どの時代でも常に効く手法はない。いくらデータを回しても見つからない。
- **探すのは「今の相場で強い武器」。** 現在の相場で強いパターン、RR（損切り幅に対する利幅）の良いエントリーポイント、といったエッジ（優位性）。
- **効く・効かないは時代で変わる。** 昔は効いて今は効かないもの、今は効くが昔は効かなかったものは普通にある。**昔は効かなかったという理由では捨てない。** 現在に近い時点で効いているものを重視する。
- **勝率ではなく RR。** たとえばブルフラッグは「形ができたときに上に走りやすい」ことに賭けるもの。価値は勝率よりも、「強い形なので浅い損切りで大きな利幅を狙える」ことにある。
- **検証は必要。** 目的は「万能さの証明」ではなく、「その武器が今、本当に切れるか」の確認。直近だけ良いものには偶然の当たりも混ざるため、偶然かどうかの確認は必ず行う（5章）。
- **人間にはできない量の検証をする。** 出来高とチャートの形だけに偏らせない。数値として使える情報はすべて使い、考えられるパターンはできる限り検証する（2章）。
- オーナーの補足（2026-10-27）：上の考え方は「根っこにある考え」であり、これに**固執しすぎない**。結果を見て柔軟に判断する。

### 評価の物差し
1. **R で測った期待値**：チャートの根拠のある損切りまでの幅を 1R とし、1回あたり平均で何R取れたか（コスト差し引き後）
2. **右側の大きさ**：損切りに触れる前に +2R・+3R・+5R・+10R に届いた割合、上位10%の取引の平均
3. **地合いを除いた力**：同じ日の対象銘柄全体の平均との差（超過リターン）
4. **今の相場での強さ**：直近の期間の成績を主に見る（5章）
- 勝率は参考として表示するだけで、良し悪しの判断には使わない。
- 日足データなので、デイトレードは対象外。**数日〜数か月のスイング以上**が対象。

### 既知の限界（受け入れる）
- 上場廃止になった銘柄の株価は取れないため、対象Aは「生き残った銘柄」に偏る。対象Bも、廃止された元構成銘柄の分は欠ける。
- アナリストの決算予想（コンセンサス）は無料で手に入らないため、「予想との差」は使えない。決算への株価の反応で代わりにする。
- 個別銘柄のオプションは過去データがないため、過去の検証には使えない（デモトレードで記録が貯まってから使う）。

## 2. 使う情報（出来高とチャートの形だけにしない）

条件を「はい／いいえ」で決め打ちするだけでなく、**数値そのもの**を使う。
- 「どこからが高いか・低いか」の境目は人が決めず、データから見つける（4章）。
- 水準（高い／低い）と変化（上がっている／下がっている）の両方を使う。
- 水準は「過去と比べてどのくらいの位置か」（例：過去5年のうち何%の位置）でも表す。

### 2-5. 先行指標の検証
「ある指標が動いた後、数週間〜数か月後に株（市場全体・セクター・銘柄のタイプ）がどう動いたか」を、**時間差をつけて**調べる。
- 例：金利差の反転、信用スプレッドの縮小への転換、失業保険申請のピークアウト、銅÷金の上昇などが、何週間後の何に効いているか。
- 時間差は1週間〜6か月で調べ、効き方が安定している時間差を探す。
- 先行指標として効いたものは、銘柄の条件と組み合わせて使う（例：「信用スプレッドが縮小に転じてから4週間以内の、小型株のブレイクアウト」）。

### 2-6. セクター・業種の循環（セクターローテーション）
- **使うデータ**
  - 11のセクターETF：テクノロジー、金融、ヘルスケアなど。
  - 24の業種ETF：半導体、バイオ、地銀、住宅建設、石油探査、金鉱株、防衛、航空など。
  - 8のファクターETF：モメンタム、クオリティ、低ボラ、バリュー、グロースなど。
- **見るもの**
  - 各セクターの市場全体に対する強さ、その順位と順位の変化。
  - ピークアウト（相対的な強さが高値から一定以上落ちたこと）。
- **調べるパターン**
  - 「セクターXがピークアウトした後、何週間後にどのセクターが強いか」を、すべての組み合わせ（35×35）と時間差で調べる。
  - 「強いセクターの中の、さらに強い銘柄」「出遅れていたセクターが反転し始めたときの銘柄」なども、銘柄の条件として使う。
- **銘柄の所属セクター**（どちらも、その時点で分かる情報だけを使う）
  - SEC に登録されている業種コード（SIC コード）を取得して使う。**未取得のため、合意後に取得する。**
  - あわせて、株価がどのセクターETF・業種ETFと最も連動しているか（過去250日の値動きの相関）でも判定する。

### 2-7. 過去データがないもの
- 個別銘柄のオプション（プット・コール比率、IV など）は2026年10月22日からしかないため、過去の検証には使えない。

## 3. 方法A：シグナルの後、株価はどう動いたか（イベントスタディ）

売買ルールを決めずに、シグナルの**後の値動きそのもの**を測る。

- 起点：シグナル日の翌日の寄り付き
- 測る期間：1・3・5・10・20・40・60・120営業日後
- 測るもの

  | 指標 | 意味 |
  |---|---|
  | 平均・中央値の騰落率 | 全体としての伸び |
  | **同じ日の対象銘柄全体の平均との差** | 地合いの影響を除いた「その条件の力」（対象Bは S&P 500 構成銘柄の平均との差） |
  | 期間中の最大の上昇幅（MFE）・最大の下落幅（MAE） | どこまで伸び、どこまで逆行したか |
  | **損切りの候補ごとの R の伸び** | 損切りの置き方の候補（6章）それぞれについて、損切りに触れる前に +1R・+2R・+3R・+5R・+10R に届いた割合と、到達までの日数 |
  | 騰落率の分布（下位10%・上位10%） | 当たりの大きさと外れの大きさ |

- **値動きの大きさで分けて見る**：ATR（1日の平均値幅）÷株価で4段階に分け、値動きの大きい銘柄を不利に扱わない。
- **局面で分けて見る**：同じパターンを、マクロや市場の局面（2-4章）ごとに分けて比べる。例：原油が高いとき・低いとき、金利が上昇中・低下中、VIX が高い・低い。
- **強い日の分析**：シグナルが同じ日に大量に出た日（暴落後の反発など）に、どんな特徴の銘柄が特に強かったかを比べる。

## 4. パターンの探し方（数の上限は設けない）

- **数の上限は設けない。** 複数の情報が重なったときに強くなる可能性を捨てないため。
- 探し方は次の4つ。
  1. **段階的に条件を足していく探索**：1個 → 2個 → 3個 → … と、各段階で成績の良い上位を残して次の条件を足す。成績が改善しなくなるか、件数が少なくなりすぎたら止める。
  2. **機械学習（勾配ブースティング）**：数値の情報をすべて入れ、「どの情報がどの値のときに大きく上がったか」を学ばせる。
     - 次のものを取り出す。
       - 効いている情報の順位
       - その数値が高い・低いでリターンがどう変わるか（境目がどこにあるか）
       - 情報どうしの組み合わせの効果（例：原油高のときだけ効くパターン）
     - 予測の値が高い銘柄の成績も、そのまま「確度の高いシグナル」として評価する。
  3. **決定木によるルール抽出**：成績の良い枝を「Aが○以上 かつ Bが○以下 …」というルールとして取り出す。人が思いつかない組み合わせも拾える。
  4. **先行指標とセクター循環の時間差の検証**（2-5・2-6章）。
- 1つのパターンに必要な最低件数：探す期間で30件以上。それより少ないものは「参考」として別枠で表示する（出現は少ないが強いパターンを捨てないため）。
- 試した組み合わせの数は必ず報告する。

## 5. 期間の使い方と判定（今の相場を重視する）

### 5-1. 探す期間と確かめる期間
| 期間 | 使い方 |
|---|---|
| **2010〜2024年** | パターンを探す期間。ただし判定は**直近3年（2022〜2024年）を主**にする。古い時期は捨てる理由にしない |
| **2025年1月〜現在（約1年10か月）** | 探すときには一切使わない「確かめる期間」。目的が「今の相場で効くか」なので、最も直接的な確認になる。全銘柄が対象なので件数は十分に出る |
| **これから先** | デモトレードで、まったく新しいデータで確かめる |

- 探すときは、保有期間の結果が2024年中に終わる行だけを使う（2024年末のシグナルの60日後＝2025年の値動きを使わない）。
- **2025年1月〜現在だけで効くパターンも、別に探す**（オーナー指示 2026-10-27）。この期間の中で見つけたものは確かめる期間がないため、判定は「観察」以上にはしない。デモトレードで確かめる。2010〜2024年で探したものとは分けて表示する。
- オーナー判断（2026-10-27）：「今の相場」は直近3年を主とし、直近1年も併記する。

### 5-2. 偶然かどうかの確認（直近を重視しつつ、ここは必ず行う）
- 何千通りも試せば、直近の成績が良いものは偶然でも出てくる。そのため次の確認を必ず行う。
  - **確かめる期間（2025年〜）でも効いているか**
  - **上位5日を除いた成績**：特定の数日（暴落後の反発など）だけに頼っていないか
  - **日ごとにまとめた t 値**：同じ日に大量に出たシグナルを独立とみなさない
  - **直近の中での再現**：直近3年の前半と後半の両方で効いているか
- 古い時期の成績は「**寿命の目安**」として表示だけする。
  - 昔から効いている → 長く通用している武器（比較的安定している可能性）
  - 最近だけ効いている → 新しい傾向（効かなくなるのも早い可能性があるので、デモトレードで劣化を監視）
- 今の局面に近い過去の時期（2-4章の局面が似ている時期）の成績も、参考として並べる。

### 5-3. 判定
| 段階 | 条件 | 扱い |
|---|---|---|
| **主力候補** | 直近3年で R の期待値がプラスかつ地合いより良い、確かめる期間でもプラス、上位5日を除いてもプラス | デモトレードに入れる |
| ├ 長寿命 | 主力候補のうち、古い時期でもおおむねプラス | 印を付ける（比較的安定） |
| └ 新しい傾向 | 主力候補のうち、古い時期は効いていない | 印を付ける（少額で始め、劣化を監視） |
| **観察** | 直近3年は強いが、確かめる期間で件数が足りない、または弱い | 記録し、デモトレードで追跡（資金は入れない） |
| **参考** | 件数が30件未満 | 別枠で表示 |
| **不採用** | 上記以外 | 理由を記録 |

- 件数が10件未満の期間は、判定に数えない。

## 6. 損切り・利確の考え方（一律に決めない）

オーナー判断（2026-10-27）：損切りは「チャートの根拠がある場所」を基本にする。ただし、**毎回一律に決めず、保有期間の長さや確度の高さに応じて変える。**

### 6-1. 損切りの候補（すべて測り、パターンごとに最も良いものをデータで選ぶ）
| 候補 | 置き場所 | 向いている場面の想定 |
|---|---|---|
| シグナル日の安値の少し下 | 最も浅い | 短期・ブレイクアウト直後など勢いの確認がとれている場面 |
| 直近の押し安値（5・10・20日の安値）の少し下 | 中くらい | スイング |
| 移動平均線（20日・50日）の少し下 | 中〜深い | トレンドに乗る中長期 |
| ATR の倍数（1.5・2・3倍） | 値動きの大きさに合わせる | 値動きの大きい銘柄 |
| フラッグの下辺・ベースの下限など、パターン自体の形 | パターンごと | チャートパターン |

- 「少し下」の幅（ATR の何割か）も複数試す。
- 方法Aで、**パターン × 保有期間 × 損切りの候補**のすべての組み合わせについて R の伸びを測る。そのうえで、どの置き方が最も R の期待値が高いかを選ぶ。

### 6-2. 確度と保有期間に応じた調整（方法Bで検証）
- **確度**：機械学習の予測の値の高さや、条件がいくつ重なっているか。確度が高いときに、損切りを広めにする（持ちこたえる）、または利確を遠くにする（大きく取りに行く）と成績が上がるかを検証する。
- **保有期間**：短期・スイング・長期で、損切りと利確の型を分ける。
- 利確も一律にしない。次のものを比べる。
  - 固定の R
  - 直近の高値（抵抗線）
  - トレーリング（最高値から ATR の倍数、または移動平均線割れで決済）
  - 一部を利確して残りを伸ばす

## 7. 方法B：売買ルールを付けた場合の損益

方法Aで有望だったパターンに、6章の損切り・利確を組み合わせて、実際の損益を測る。

### 7-1. 買い方
| 種類 | 内容 |
|---|---|
| 寄り付き買い | シグナル翌日の寄り付きで買う |
| 押し目の指値 | 翌日に、シグナル日の終値または安値付近まで下がったら買う（届かなければ見送り） |
| 高値更新で買い | 翌日に、シグナル日の高値を超えたら買う（勢いの確認） |

### 7-2. 測るもの
- 1回あたりの平均損益（%と R）、合計、平均利益／平均損失（勝率は参考）
- **右側の大きさ**：上位10%の取引の平均、最大の取引、利益全体に占める上位の取引の割合
- 保有日数の分布
- 期間別（直近3年・直近1年・確かめる期間・古い時期）
