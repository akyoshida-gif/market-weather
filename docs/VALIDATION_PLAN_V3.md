# 検証計画 第3版：教科書のセットアップ × 相場の文脈

状態：**基本方針は合意済み（2026-10-30）**　作成 2026-10-30
これまでの検証計画（VALIDATION_PLAN.md）の方法A〜Cは、無作為な総当たりと全局面の平均に偏り、勝てる形にならなかった。本書はそれに代わる進め方を定める。データの取り扱い（PIT、データの誤り、手数料など）は VALIDATION_PLAN.md の決まりをそのまま使う。

---

## 0. 反省と考え方

### これまでの反省
- 20万通り以上の条件を機械的に組み合わせた（偶然の当たりを拾いやすい）
- 「1年の騰落率が上位20%」のような、売買の理由にならない条件を使った
- 全銘柄・全局面を平均した（上昇局面と下落局面で意味の違うシグナルを混ぜた）
- 最後に、大ざっぱな条件のシグナルを出た順に機械的に買った（厳選して入っていない）

### 考え方（オーナーと合意）
- **誰も知らない新しい何かを見つける必要はない。** テクニカルの教科書にある既存の手法を、順当に使う。
- 知りたいのは、**「既存の手法が、どの相場で効くのか」**。
- **全銘柄に効く必要はない。** 限定的でも、確度が高いか、大きく取れる場面を見つけて、そこでだけ入る。何もないときは現金で待つ。
- **文脈が大事。** 上昇局面と下落局面で似たシグナルが出ても、意味は違う。
- **後から分かったことを使うのは禁止。** 局面・ステージ・形は、すべてその日に分かる情報だけで判定する。
- 「自分が勝つために検証するなら、どうするか」を常に前提にする。

## 1. 上から順に絞る（トレーダーの手順）

| 手順 | 中身 | 主に使うデータ |
|---|---|---|
| 1. 相場の局面 | 上昇・調整・下落・底入れ・高い変動の5つ（その日に分かる情報だけで判定） | 指数のトレンド（日足・週足）、上がっている銘柄の割合、新高値・新安値、VIX、信用スプレッド、金利、心理（プット・コール、NAAIM、信用残高） |
| 2. セクター | 強いセクター・業種を選ぶ | セクター・業種の ETF の強さ、業種コード |
| 3. 銘柄のステージ | ワインスタインのステージ1〜4（週足の30週線の向きと位置）。買うのはステージ2か、1→2の移り目だけ。ミネルヴィニのトレンドテンプレートも使う | 週足・月足、移動平均線 |
| 4. 銘柄の質 | 業績の伸びと加速、決算への反応、機関投資家の増減、インサイダーの買い、主導株かどうか | SEC の XBRL、13F、Form 4、決算発表 |
| 5. 買いの形 | 教科書どおりのセットアップ（2章） | 日足・週足、出来高、指標 |
| 6. 注意 | 増資・希薄化、決算の直前、FOMC・CPI の前後、売買停止、空売りの状況 | 開示、予定表、空売りのデータ |

## 2. セットアップ（検証の前に、なぜ効くのかと、ルールを書いて固定する）

| 局面・ステージ | セットアップの例 |
|---|---|
| 上昇 × ステージ2 | ベース（カップウィズハンドル、平らなベース、VCP、上昇三角形、フラッグ・ペナント）を出来高を伴って上抜け／10・20・50日線への押し目で反転のローソク足（ハンマー、包み足）／MACD がゼロより上でゴールデンクロス／決算での強い反応の後の押し目 |
| 底入れ × ステージ1→2 | 逆三尊・ダブルボトムのネックラインを出来高を伴って上抜け／RSI の強気のダイバージェンス／支持線での明けの明星／ゴールデンクロス |
| 下落 | 原則は現金。やるとしても、極端な売られ過ぎからの短い反発を少額で |
| 天井のサイン（三尊、ダブルトップ、首吊り線、宵の明星、弱気のダイバージェンス） | 買いだけなので、売る判断・入らない判断に使う |

- セットアップごとに、**検証の前に**「なぜ効くのか」「入る場所」「損切り」「利確」を書いて固定する。結果を見てから何度も変えない。
- 調べる数は30〜50種類ほど。意味のある組み合わせだけを作る。

## 3. 売買のしかた（実際の売買と同じにする）

- **入り方**：買い場（ピボット）の少し上に逆指値の買いを置き、上抜けたときだけ買う。買い場から5%以上離れていたら追いかけない。
- **損切り**：形が崩れる場所（逆三尊なら右肩の安値、カップならハンドルの安値など）。上限は −7〜8% を目安。
- **利確・手じまい**：形から出る目標の値幅、高値からの追いかけ、出来高を伴う50日線割れ、急な上昇（クライマックス）。
- **買い増し**：最初の買いに利益が出てから、買い足す（ピラミッディング）。
- **全体の量**：相場の回復が確かめられるにつれて増やす（フォロースルー日など）。下落局面では現金も立派な持ち方。同じセクター・同じ動き方に偏りすぎない。

## 4. 検証のしかた（本物かどうかを確かめる）

| 確かめ方 | 中身 |
|---|---|
| 局面 × ステージ × 形 | それぞれを分けて成績を出し、「どの局面で、どの形が効くか」の地図を作る |
| 適当に買った場合との比較 | 適当な銘柄・日に買い、同じ出方で売った場合と比べる。S&P 500 をただ持つ場合とも比べる |
| ウォークフォワード | 毎年、その年までのデータだけで使う形を決め、次の1年で売買する。2015〜2026年で繰り返す |
| 数値の安定 | 損切り幅などを少し変えても崩れないか（とがった1点でなく台地を選ぶ） |
| モンテカルロ | 取引の順番を入れ替え、資金がどこまで減りうるか、負けがどれだけ続くかを測る |
| 目視の確認 | 形の判定を、形ごとに20件ほどチャートで確かめる（**オーナーも協力**） |
| これまでの確かめ方 | 時期を分けても崩れないか、上位5日を除いても残るか、2025年以降でも通用するか |

- 各データについて、「形だけ」と「形 ＋ そのデータ」を比べ、成績が本当に良くなるかを確かめる。良くならないデータは使わない。
- 測るもの：出た回数、勝率、平均の R、+3R 以上に届いた割合、保有日数、資金管理込みの年率と最大の資金の減り。
