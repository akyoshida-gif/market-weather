# 状態の表（アトラス）による探索：記録

オーナーの指示（2026-11-09・11-12）：
- 形や指標の名前をなぞる表面の分析をやめる。値動き・出来高・状況を細かく数値にして掛け合わせ、段階ごとに実証する。
- 理由は要らない。数字で勝てればよい。
- 直近は直近で調べる。

## 1. 材料（`src/mw/research/atlas.py`、`jobs/atlas_build.py`）

- 対象は米国株 5,956 銘柄。**今上場している銘柄だけで、上場廃止は含まない（survivorship_biased=true）**。値動きの荒い銘柄・弱い銘柄の成績は、実際より良く見える。銘柄間の差の結論（4章の「下の組を避ける」など）は、上場廃止を含めて確かめるまで割り引いて読む。2011〜2026年の約870万行（銘柄×営業日。元の株価は約1,600万行で、売買代金・株価・1年分の履歴の条件で絞った後の行数）。
- 1銘柄・1日ごとに、次の数値を作る。
  - 1本の足の中身：実体、上ひげ・下ひげ、値幅、終値の位置、窓
  - 夜間と日中の動きの積み上げ
  - 9つの期間のリターン
  - 高値・安値からの距離と日数
  - 移動平均からの距離と傾き
  - 荒さ（値幅の縮み・広がり、偏り、上げた翌日にまた上げやすいか）
  - 出来高（ふだんとの比、上げた日の出来高の割合、売りの細り、集中）
  - 最近買った人の損益（出来高で重みを付けた平均値段との差、今の値段より上で売買された出来高の割合）
  - 何日続けて上げた・下げたか
  - 大陽線・大陰線・窓の日の記憶（何日前か、その値幅のどこにいるか、窓は埋まったか）
- 主要な24個には「自分の過去と比べてどうか」を付ける（60日・250日の z値、5日の変化、変化の加速）。
- 市場全体の数値も作る。
  - 上げた銘柄の広がり、新高値と新安値の差、銘柄間の散らばり
  - VIX とその仲間、SKEW、VVIX
  - 金利・信用・ドル・原油（公表日を基準にして、その日にまだ知らない数字は使わない）
  - 暦
- 結果として、買った翌日から60日間の道筋を記録する。
  - 各期間のリターン
  - 最大の含み益・含み損
  - 利確（+0.5〜6ATR）・損切り（−0.5〜4ATR）の各幅に、何日目に届いたか
- テストで、未来の値段を変えても特徴量が変わらないこと（先読みがないこと）を確かめた。

## 2. 損切りの後に利確まで戻るか（全体、2011〜2024年3月。60日の道筋が2024年6月までに終わる行）

| 損切り → 利確 | 先に利確 | 先に損切り | 損切りの後に利確まで戻った割合 |
|---|---|---|---|
| −1ATR → +1ATR | 51% | 49% | 72% |
| −1ATR → +2ATR | 35% | 64% | 59% |
| −2ATR → +2ATR | 52% | 47% | 45% |
| −2ATR → +4ATR | 34% | 61% | 25% |

損切りの後に利確は「損切りに届いた（>0）かつ、その後の日に利確に届いた」で数えた（-1＝届かず、は除く。同じ日に両方は損切りが先とみなす）。全体では、でたらめな値動きとほぼ同じ形。60日あれば値段は上下に十分動くので、戻ること自体は優位ではない。この全体の値を基準にして、戻りやすい場面を探すのが次の課題。

## 3. 1つずつの条件と、その掛け合わせ（10日後、同じ日の全銘柄の平均との差）

数え方：探す期間は 2011〜2019年、確かめる期間は 2020年〜2024年6月。2024年7月以降は使っていない。同じ時期の行は似ているので、月ごとの成績の t値で数える（t値＝偶然では起きにくい度合い。2以上でおおむね偶然ではない、3以上ならかなり確か）。

- **銘柄の数値1つだけ**：一番良いものでも、10日で +0.05〜0.1%。コスト（往復0.1%）で消える。上位100個のうち68個は、確かめる期間でも方向が合っていた（偶然なら50個前後）。弱いが本物の傾向は多い。
- **段階的な絞り込み**：探す期間では t値が7〜8まで上がり、9年すべてで勝つ形を作れる。しかし確かめる期間では、ほぼゼロかマイナス。過去に合わせすぎ。
- **総当たりの地図（2つの数値の5×5）**：探す期間で良かった300の升のうち、確かめる期間でも勝ったのは160（53%）。偶然と同じ。
- **最初の方法の誤り**：市場全体の数値（金利・原油など）を銘柄選びの条件に使うと、「特定の時期」を選んでしまう。行の数は多く見えても、中身は数回の局面にすぎない。→ 結果を「同じ日の全銘柄の平均との差」に直し、月単位で数えるように改めた。

## 4. 機械学習で束ねる（LightGBM、時期をずらして学習と予測を繰り返す）

各年について、その前年までのデータだけで学習し、その年を予測する。学習と予測の間は、結果の期間の分だけ空ける。毎日、予測の点数で銘柄を10組に分けた。先読み対策の後の値。

| | 2014〜2019年 | 2020〜2024年6月 |
|---|---|---|
| 一番上の組（10日、他の銘柄との差） | +0.27%（t 2.8、勝った月 65%） | +0.20%（t 0.8、56%） |
| 一番上の組 − 一番下の組 | +0.63%（t 3.4、67%） | +0.63%（t 1.6、61%） |

- 先読み対策（5章）の前の値（+0.37%・+0.90% など）から、約3〜4割下がった。
- 上の組が下の組を上回ったのは11年中9年（2020年と2024年は負け）。
- 直近の期間では、**上の組を買う力はほぼない**（t 0.8）。上の組と下の組の差も t 1.6 で、偶然と区別できる水準ではない。下の組も毎年負けるわけではない（2020年 +0.43%、2023年 +0.01%）。
- 効いた数値：値動きの荒さ（ATR の大きさ）、1年のリターン、市場全体の数値（金融の引き締まり、金利、イールドカーブ、ドル、原油など）。市場全体の数値は、「どの時期に、どの銘柄の特徴が効くか」の切り替えとして使われている。
- **結論：日足の値動き・出来高と市場全体の数値を細かくして束ねても、10日後の銘柄の差を当てる力は小さい。買う武器にはならない。避ける用途に使えるかもしれないが、まだ確かめていない。**

### 極端な状態（上位・下位の1%・5%、先読み対策の後）

- 向きは安定している。探す期間で |t|≥3 だったもののうち、確かめる期間でも同じ向きだった割合は、5日後で28通り中28、10日後で17通り中17、20日後で15通り中14。ただし、2日のリターン・連続上げ・日中の上げのように、ほとんど同じ動きを測る数値が多いので、独立した証拠はこの件数より少ない。
- **避ける場面**：短期間で急騰した上位1%（2日で+8.6%以上、5日で+14%以上、日中の上げの5日の積み上げが+11%以上）は、その後10日で他の銘柄より、探す期間で0.4〜0.5%、確かめる期間で0.6〜1.0% 負ける。日中の上げの積み上げ（5日・20日）は、20日後でも、探す期間で0.6〜0.7%、確かめる期間で1.1〜1.3% 負ける。
- **買う場面（小さい）**：
  - 直近60日の売買がすべて今の株価より上で行われた底値圏（下で買った人がいない）：10日で +0.1〜0.2%。
  - 50日線から自分の過去と比べて極端に下に離れた：5日で +0.2〜0.4%。
  - どちらもコスト（往復0.1%）を少し超える程度。しかも、底値圏や大きく下げた銘柄は、上場廃止を含まないデータで成績が良く見えやすい典型で、売買の少ない銘柄はコストも大きい。**実際にはコストに負ける可能性が高い。**

## 4.5 避ける条件を今の型に掛ける（2026-11-13、`scripts/atlas/avoid_filter.py`）

「短期間の急騰の直後（2日で+8.6%以上、5日で+14%以上、日中の上げの5日の積み上げが+11%以上のどれか）」の買いを除くと、今の型の成績が上がるかを確かめた。デモの型と候補の型のうち買いの43通りを1回ずつ再現し、売買を「急騰直後」と「それ以外」に分けて比べた。

- 急騰直後の売買が両方の期間で10回以上あって比べられた34通りのうち、両方の期間で急騰直後のほうが劣っていたのは9通り。
- 全部の型をまとめると、確かめる期間で急騰直後は −0.02R、それ以外は −0.01R で、差はない。ただし、この平均は件数の多い RSI2 と押し目の型でほぼ決まっている。
- 一部の型では、急騰直後が劣る傾向がある。
  - 小さい値幅からの上抜け（squeeze_break の c0.8）：確かめる期間で −0.11〜−0.27R の差
  - 押し目の型（pullback_rs）：探す期間で −0.08〜−0.10R の差
  - ただし、これらは互いにほぼ同じ売買の派生で、squeeze_break は件数も少ない（147〜276回）ので、採用する根拠にはならない。
- 急騰を狙う型（ギャップの勢いに乗る型、パニック買いの一部）は、急騰直後のほうがむしろ良い。
- **結論：全体としては、避ける条件は今の型に効かない。**
  - 理由は、銘柄間の小さな差（10日で −0.4〜1%）が損切りの幅を単位にした損益では埋もれること、各型がすでに独自の条件で絞っていること、と考える（どちらも推測。確かめていない）。
- 機械学習の下位の組を掛ける検証は、まだしていない。
- 気づいたこと：RSI2 の型（k2.0）の探す期間が −0.8R と極端に悪い。損切りの幅がほぼ0の売買で、損益の値が大きく振れているとみられる（推測）。やり残し D6。

## 5. レビューで分かった先読みと、その対策（PR #42）

- **株価の水準**：株価は後から分割で調整されるので、後で株式併合する会社は、過去の株価が高く見える。当時の実際の株価を復元して使う。
- **分割の補修**：毎日の取得が直近7日分しか取り直さないため、分割が過去の株価に反映されていない銘柄がある（比率1.25倍以上の分割3,190件のうち65件）。段差は、分割の日にあることもあれば、1〜10日前（取り直した範囲の始まり）にあることもある。分割の日から10日前までの範囲で、段差の日を2段階で決める。
  - まず、前の3日と後の3日の終値の真ん中の値の比が、分割比と合う日を候補にする。1日だけの値の跳ねに引きずられないため。
  - 候補の中から、その日の1日の動きが分割比と一番合う日を選び、それより前の株価を直す。
  - 比率1.25倍未満（主にスピンオフ）は、普段の値動きと区別できないので直さない。
  - この研究に使った株価（2026-11-09 に取得）では、補修の後も14件が残った。すべて2026年9〜10月の低位株で、分割前と分割後の値が1日おきに入り混じっていた（取得側の不具合）。PR #43 で取得側を直し、2026年8月以降に分割した210銘柄の全期間を取り直した後は、未反映が65件→19件、研究の補修をかけると0件（2026-11-12、`scripts/atlas/check_splits.py`）。
  - 既知の限界：調整済みのデータで、分割の直前10日間に分割比と同じくらい本当に動いた日があると、誤って直す。値段だけでは区別できない。取得日時（ingested_at）で見分けるのが正しい（やり残し D5）。
- **FRED**：米国の引け後に公表されるので、公表日の翌日から使う。過去の値は改定後の値（初回の公表値ではない）。
- **期間の境目**：探す期間の最後の行の結果が、確かめる期間の値動きを含まないように、結果の期間の分を除く。60日の道筋は60営業日分を除く。機械学習も、学習と予測の間に結果の期間の分を空け、値の切り方は学習の行だけで決める。
- 2章・4章の数字は、対策の後に計算し直した値（2026-11-12）。

## 7. 時期選び：市場全体が上がりやすいのはいつか（2026-11-13、`scripts/atlas/timing.py`・`timing_long.py`・`weak_dip_bt.py`）

### 1つずつ（2011年〜、S&P 500 の20日後・60日後）
- 「市場が弱った後」は、その後60日の S&P 500 が上がる**傾向があった**。探す期間で基準と1%以上違った38通りのうち、32通りが確かめる期間でも同じ向き。ただし38通りは互いによく似た数値（50日線からの距離、20日のリターン、出来高の流れなど）で、独立した確認ではない。
  - 例（60日後、基準との差。探す期間 → 確かめる期間）：S&P 500 が50日線の下 +2.2% → +1.8%、SKEW が低い +2.2% → +3.0%、VIX÷VIX3M が高い +2.1% → +2.9%、全銘柄の出来高の流れが売りに傾く +1.7% → +1.4%
  - この表は月ごとの t値を出していない（日ごとの平均の差）。
- 束ねて「上がりそうな時だけ持つ」は、持ち続けに負けた（2014〜2019年 1.57倍 対 1.74倍、2020〜2024年6月 1.37倍 対 1.69倍）。2022年の下げは避けたが、2023〜2024年の上げを逃した。

### 弱った条件の重なり（1990年〜2024年6月、S&P 500 指数・VIX・SKEW）
- 4つの条件（50日線の下、20日のリターンが低い、SKEW が低い、VIX が自分の過去1年と比べて高い。境目は1990〜2009年の弱い方の20%）のうち3つ以上が重なった局面は64回。最初の日に買って60日後は平均 +3.2%（全日の平均 +2.2%）、最悪 −27.5%。2000年代（下落相場）は効かない。
- 弱る前の相場の流れで分けると：

| | 回数 | 60日後の平均 | 上がった割合 | 最悪 |
|---|---|---|---|---|
| 上昇相場の中で弱った | 45回 | +3.7% | 69% | −9.4% |
| 下落相場の中で弱った | 19回 | +1.9% | 74% | −27.5% |

- **注意：この数字は検証外の数字ではない。** 境目を決めた1990〜2009年を含む。4つの条件は2011年以降の結果（上の「1つずつ」）を見て選んだ。「上昇相場の中で」に絞ったのも、全期間の結果を見た後。
- 年代で見ると、2020年代は4回で平均 +0.8%、上がったのは1回だけ。

### 売買の形での再現（2011年〜、買いの合図が2024年6月の60日前までの回だけ。どの回も60日分が2024年6月までに収まる）と結論
- 比較：同じ期間の、すべての日の S&P 500 の60日後の平均 +2.7%（上がった割合 74%）。
- 押し目で S&P 500 を買う：17回、平均 +2.6%、10勝、最悪 −7.4%。**普段と同じ。**
- 押し目でベータ×強さの上位10銘柄を買う（3ATR）：19回、平均 +1.0%（中央値 +1.1%）、10勝、最悪 −18.5%。**普段の S&P 500 より悪い。**
- SKEW の境目（111.8）は、2011年以降の0.3%の日でしか当てはまらない。2011年以降は、実際には残りの3つの条件で判定していた。
- **結論：押し目の型は、2011年以降は普段の S&P 500 と変わらず、デモに入れない。** 本番のコード（相場の状態・型の部品）にも入れない。研究のスクリプトの中だけで計算する。

## 8. 動き・経過の数値（2026-11-13、`src/mw/research/dynamics.py`・`jobs/dyn_build.py`・`scripts/atlas/dyn_search.py`・`ml_compare.py`）

オーナーの指摘：瞬間の値ではなく、経過による変化（距離が縮まっているか、その間の出来高と価格、状態に入ってからの日数）と食い違い（ダイバージェンス）。
案の一覧は `docs/IDEAS.md`。状態の表の横に `dyn/`（76個の t_* の数値）を足した。中身はモジュールの説明のとおり。

結果の物差し（5営業日ごとに間引き、106万行。探す 2011〜2019、確認 2020〜2024年6月）：
- 20日後の、同じ日の全銘柄の平均との差
- 20日以内に −10% 以上下げたか（大負け）。正確には「20日の最安値が、買いの合図の日の終値から見て −10% 以上下」（翌朝の窓の分だけ、入った値からの比率とずれる）。値動きの激しい銘柄ほど当然よく下げるので、**同じ日・同じ激しさ（ATR÷株価の5組 × ATR20÷ATR120 の3組）の銘柄どうしの差**で見る。全体の率は 24.9%。

### 上がり方（市場平均との差）：ほとんど予測できない
- 探す期間で t値3以上は4段階だけで、差は探す期間 ±0.11〜0.22%、確認の期間 ±0.13〜0.35%。確認の期間でも t値3以上なのは「250日の安値から62日以内（最近1年の安値をつけたばかり）」の −0.11% / −0.35% だけ。
- AI のモデル（4章と同じ作り、20日後、10営業日ごとに間引き）に動きの数値を足しても良くならない：一番上の組 2014〜19 +0.23%→+0.20%、2020〜24 +0.17%→−0.15%。上−下 2020〜24 +0.74%→+0.36%。足さない側の数値もデータの並び順だけで ±0.03〜0.1% 動く（学習の乱数）ので、その程度の差はぶれの範囲。

### 大負けの率：2つの期間で同じ向きの差がたくさんある（探す期間で t値3以上の157段階のうち149）
同じ激しさの銘柄どうしでの差（pt）。探す / 確認。
- 危ない側
  - 60日の安値から +22% 以上戻している：+2.9 / +2.4
  - 60日の上昇率が全銘柄の上位2割：+2.1 / +3.1
  - 200日線から +15% 以上離れている：+2.6 / +2.4
  - 下げた日の出来高が、前より大きく細っている（「売りが枯れた」形）：+1.1 / +1.8 → **通説と逆**
  - 10日の出来高が前の10日より減っている：+0.8 / +0.6
- 安全な側
  - 10日の出来高が前の10日より 33% 以上増えている：−1.9 / −1.7
  - 安値を更新したのに、出来高はその前の安値のときより多い：−2.6 / −3.6
  - 200日線の近く（−7%〜+1%）：−1.2 / −1.5
- 200日線の上下にいる日数 × 距離（オーナーの問い）。括弧は大負けの率の差の t値。
  - 日数の数え方：移動平均が計算できるようになってから最初に線をまたぐまでは「いつ始まったか分からない」ので数えない（レビューの指摘で修正。直す前は上場直後の期間も「下にいる」と数えていた。直した後も結果はほぼ同じ）
  - 200日線を割って6〜20日、深さ −20%〜0%：探す −1.6〜−2.7（t −3.4〜−5.9）、確認 −2.4〜−3.4（t −4.4〜−7.6）。**2つの期間とも、はっきり安全側**
  - 割って2〜5日、深さ −10%〜0%：探す −1.6〜−2.9（t −5.6〜−5.7）、確認 −1.7〜−3.0（t −3.2〜−6.1）
  - 割って121日以上：深さ −20% 以下は 探す +2.0（t 4.1）、確認 +2.2（t 4.2）。それより浅い段は +1.0〜+2.4 だが t値 0.8〜2.4 で弱い
  - 200日線から +20% 以上で、上にいるのが21日以上：探す +3.2〜+4.7（t 5.7〜7.7）、確認 +1.9〜+4.3（t 3.0〜3.5）
  - 上抜けて2〜5日で +10〜20% 離れている：確認の期間だけ +4.9（t 2.6。探す期間は −0.3 で、向きがそろわない）
  - **同じ「200日線の下」でも、割って間もない（2〜20日）ほうが、長く深く下にいるより安全。** ただし20日後の上がり方の差はどの升も ±1% 以内で、t値3を超えるのは1升だけ。
- 注意：差は全体の率 24.9% に対して ±1〜4pt。単独で売買の判断を変えるほどではない。使い道は「拒否権」（IDEAS 45）の材料。

## 9. 夜間だけ持つ・日中だけ持つ（2026-11-13、`scripts/atlas/overnight.py`・`overnight_card.py`、IDEAS 49）

- 全営業日・全銘柄の夜間の1回の平均（手数料なし）：2011〜19 +0.029%、2020〜24 +0.044%。日中は全営業日では計算していない。
- **間引きの落とし穴**：10営業日ごとに間引いて探したとき（`overnight.py`）は「値動きの激しい銘柄・日中に売られ続けた銘柄を夜間持つと1晩 +0.2%」に見えた。全営業日で再現すると +0.06% 前後。原因は3つ：
  1. 1日の値動きは全銘柄がそろって上下するので、日数を間引くと、たまたま上げた日・下げた日に左右される
  2. 同じ日の全銘柄の平均を引いていない（市場全体と一緒に動く分が残っている）
  3. 269個×5段階からよいものを選んだので、偶然の当たりが混ざる
  **1日の結果を見る検証は、間引かず、同じ日の平均を引いて行う。**
- 全営業日での再現（`overnight_card.py`。条件に合う銘柄を毎日引けで均等に買い、翌朝の寄りで売る。分割の補正あり。翌朝の結果を見て除く処理はしない）：

| 条件 | 2011〜2019：1回の平均 / 年率 / 最大の落ち込み | 2020〜2024年6月：同じ |
|---|---|---|
| 全銘柄（比較） | +0.029% / +7% / −18% | +0.044% / +11% / −31% |
| ATR が株価の 3.5% 以上 | +0.057% / +20% / −18% | +0.073% / +14% / −33% |
| 20日の日中の合計 −4.9% 以下 | +0.058% / +14% / −15% | +0.049% / +18% / −34% |
| 両方 | +0.071% / +21% / −16% | +0.062% / +20% / −34% |
| SPY を持ち続ける（比較） | 年率 +11% / −20% | +12% / −34% |

- 最悪の1回は −73〜−90%（一晩で大きく下げる銘柄がある）。
- 条件による全銘柄との差は、1晩あたり 探す期間 +0.03〜+0.04%、確認の期間 +0.005〜+0.03%。年に250回売買するので、買値と売値の差（スプレッド）が片道 0.02% あるだけで消える大きさ。手数料は考えない方針だが、実際に約定する値段の差は別の問題なので、**デモには入れない**。
